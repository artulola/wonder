#  💜 Wonder – Plataforma de Serviços de Beleza (Em Desenvolvimento)

## **Link do site:** [Wonder](http://136.113.181.247/auth/login/) 👈

O **Wonder** é um sistema web em desenvolvimento que busca conectar **clientes** e **prestadores de serviços de beleza** de forma prática, organizada e segura.  
Nosso objetivo é criar uma plataforma onde pessoas possam **encontrar, agendar e pagar** por serviços como cabelo, unhas, sobrancelhas, maquiagem, barba e massagem — tudo em um só lugar.  

Atualmente, o projeto está em fase de **prototipagem e implementação inicial**, com foco na construção das **principais funcionalidades** e definição da **arquitetura back-end**.

## ✨ Visão Geral

O Wonder busca resolver um problema comum: a dificuldade que clientes e prestadores enfrentam para agendar serviços de beleza com praticidade.  
O sistema será composto por três perfis principais de usuários:

- **Cliente:** procura e agenda serviços.  
- **Prestador:** oferece serviços e gerencia sua agenda.  
- **Administrador:** supervisiona o sistema via Django Admin.
